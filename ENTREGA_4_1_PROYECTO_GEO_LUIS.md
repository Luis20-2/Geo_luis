# Explicación
Geo Luis es una aplicación orientada a la gestión de empleados y sus direcciones geográficas. El sistema permite registrar empleados, asociarles coordenadas, convertirlas en direcciones comprensibles y exponer esta información mediante una API REST consumible desde web y móvil.

# Justificación
Este proyecto es importante porque permite centralizar información de personal y ubicación en una estructura moderna y escalable. Resuelve la necesidad de consultar, registrar y administrar datos geográficos de forma remota, segura y organizada.

# Alcance
La API incluye las siguientes funciones:
- Registro de usuarios
- Inicio de sesión seguro
- Gestión de empleados
- Gestión de direcciones
- Consumo desde frontend web y app móvil
- Documentación interactiva de endpoints

# Tecnologías utilizadas
- Python
- Django
- Django REST Framework
- JWT
- Swagger / OpenAPI
- SQLite
- CORS Headers

# Conclusión personal
Este proyecto permitió aplicar principios reales de arquitectura backend, seguridad y diseño REST. La separación entre backend, frontend y cliente móvil facilita el mantenimiento y demuestra una base profesional lista para futuras mejoras como despliegue en nube, pruebas automatizadas y bases de datos más robustas.
